# Curramba Fast Food — sitio web

Sitio estático adaptable a móviles, listo para GitHub Pages.

## Publicarlo gratis en GitHub Pages

1. Inicia sesión o crea una cuenta en https://github.com.
2. Crea un repositorio público llamado `currambafoodtruck` (o el nombre que prefieras).
3. Sube `index.html`, `styles.css` y la carpeta `assets` conservando esa estructura.
4. En el repositorio abre **Settings → Pages**.
5. En **Build and deployment**, selecciona **Deploy from a branch**, elige `main` y `/ (root)`, y guarda.
6. GitHub mostrará la dirección pública cuando termine de publicar. Si el repositorio se llama `currambafoodtruck`, suele ser `https://TU-USUARIO.github.io/currambafoodtruck/`.

## Antes de publicar

Confirma que el nombre comercial se escribe **Curramba Fast Food** y revisa que la dirección siga vigente. No se incluyeron teléfono, correo, horarios ni precios porque no fueron proporcionados/verificados. Los tipos de comida se tomaron de listados públicos de plataformas de pedidos; confirma el menú vigente con el negocio.
